


# SOULBOUND — Chapter 1

**An original browser-based adventure game.**

Welcome to SOULBOUND, an adventure where exploration, combat, secrets, and challenges await.

## 🎮 Play the Game

[**PLAY SOULBOUND — Chapter 1**](https://robloxparkourmaster2-boop.github.io/SOULBOUND-Chapter-1-/)

## 🕹️ Controls

| Key | Action |
|---|---|
| WASD | Move |
| E | Interact |
| SPACE | Jump |

## ⚠️ Important — Ending Instructions

During the final sequence, you may need to press **E multiple times** to continue the dialogue and trigger the next events.

**Don't stop after the first interaction!** Keep pressing E when prompted until the sequence progresses.

## ⚔️ Features

- Explore the world of SOULBOUND.
- Discover hidden secrets and collect items.
- Fight enemies and powerful bosses.
- Unlock equipment and upgrades.
- Experience the Chapter 1 storyline.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Start playing!
